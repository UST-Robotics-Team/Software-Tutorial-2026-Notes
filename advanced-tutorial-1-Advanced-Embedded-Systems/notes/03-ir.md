# 3. IR (Infrared) Sensor — CW2

An **infrared (IR) sensor detects infrared light**, which is invisible to the
human eye. The TCRT5000 used here is a **reflective IR sensor**: it shines light
at a nearby surface and detects the light reflected back.

## 1. How this sensor works

![TCRT5000 module and signal labels](images/ir-module-photo.png)

Use the actual pad labels and [connection guide](../hardware/pin-mapping.md);
the photo does not establish Mainboard connector positions.

It contains an **IR emitter** that sends light and a **phototransistor** whose
current changes with the light it receives. The module's circuit converts that
response into a voltage.

This makes it useful for detecting a line, a contrasting surface or a nearby
object. In CW2, we compare black and white paper at a fixed height. Material,
distance and angle all affect the reflection, so it is not a direct color or
distance measurement.

The module exposes the reading in two forms:

![Analog and comparator paths](images/ir-two-output-paths.png)

| Output | Signal | STM32 reads it with | Who decides BLACK/WHITE? |
| --- | --- | --- | --- |
| A0 (AO) | Varying voltage | ADC: Analog-to-Digital Converter | Your software threshold |
| D0 (DO) | HIGH/LOW | GPIO: General-Purpose Input/Output | Module comparator |

The potentiometer adjusts D0's comparator threshold, not A0 directly.
Your software label can therefore differ from D0. A0 retains the numerical
reading; D0 supplies one decision without showing how close it is to the boundary.

## 2. Choose a threshold from samples

At one fixed height, suppose these **illustrative** readings occur:

| Surface | Five raw samples | Range |
| --- | --- | --- |
| White | 810, 840, 825, 860, 835 | 810–860 |
| Black | 2740, 2810, 2785, 2840, 2795 | 2740–2840 |

```text
threshold = (largest white + smallest black) / 2
          = (860 + 2740) / 2 = 1800
```

Black is higher in this example, so use `raw >= threshold`.
Measure your module's actual polarity: `IR_BLACK_IS_HIGH=1` selects that rule;
`0` selects `raw < threshold`. The samples justify the rule; color alone does not.

If ranges overlap, stabilize height, angle and lighting, then sample again.
A threshold cannot reliably separate overlapping ranges.

A0 is not a unique distance: material and separation both change reflection.
Keep the sensor at a fixed, small height. The TCRT5000 component's peak operating
distance is about 2.5 mm under datasheet conditions; check the actual module.

## 3. CW2: sample A0, then classify

Use the single `projects/MainBoard` Debug project for both CW2 and CW3. Follow
[setup](../hardware/classwork-setup.md). The complete IR connection is:

| TCRT5000 pin | UART2 header | Prepared MCU function |
| --- | --- | --- |
| VCC | V, reported 3.3 V | Module power |
| D0 | T | PA2, GPIO input |
| A0 | R | PA3, ADC1 Channel 3 |
| GND | G | Common ground |

![IR on the UART2 header](images/ir-uart2-wiring.png)

Confirm supply and labels, power off before wiring, and keep USART2 disabled.
The app already calls `IR_Read()` and displays A0/D0 before you edit anything.
If a conversion fails, it shows `IR ADC ERROR` and skips your classifier.

1. Build Debug, flash and Continue. Confirm the title `IR + ULTRASONIC` and
   changing A0/D0. Leave the ultrasonic sensor connected on PA0/PA1.
2. At a fixed height, record A0 samples over white and black:

   | Surface | Five raw samples | Minimum | Maximum | D0 |
   | --- | --- | --- | --- | --- |
   | White | _____ _____ _____ _____ _____ | _____ | _____ | _____ |
   | Black | _____ _____ _____ _____ _____ | _____ | _____ | _____ |

3. Choose `IR_THRESHOLD` in the gap between the two ranges. Set
   `IR_BLACK_IS_HIGH` from your observations in `Core/Inc/tutorial_config.h`.
   The default 2000/1 is an example, not your calibration. If ranges overlap,
   improve the setup and repeat before selecting a threshold.
4. In `Core/Src/student_tasks.c`, complete `CW2_ProcessIR()`: use `sample->raw`
   and an `if/else` to draw `SURFACE: BLACK` or `SURFACE: WHITE` on TFT row 2.
   High-black uses `raw >= threshold`; low-black uses `raw < threshold`.
   You do not need to add ADC initialization, a HAL wrapper or an error sentinel.
5. Save → Build Debug → Run and Debug → Continue. Test both surfaces repeatedly.
6. Adjust the potentiometer and compare D0 with your software label. The required
   classifier must use A0: merely copying D0 does not demonstrate an ADC threshold.

## 4. Demonstrate

```text
IR + ULTRASONIC
A0:2810 D0:1
SURFACE: BLACK
UART2 A0:R D0:T
```

Example values only. Ultrasonic readings remain on the same screen.
Show both surfaces, recorded ranges and the chosen threshold. Explain why A0
needs ADC, D0 needs GPIO, and their decisions can differ—even BLACK with D0 LOW.

**Extension:** hysteresis uses a higher threshold to enter BLACK and a lower
one to return to WHITE. Between them, retain the previous state to reduce flicker.

Reference: [Vishay TCRT5000](https://www.vishay.com/docs/83760/tcrt5000.pdf).
