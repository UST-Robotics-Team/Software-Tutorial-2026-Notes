## What is STM32CubeMX for 

[STM32CubeMX Website](https://www.st.com/en/development-tools/stm32cubemx.html#get-software)

STM32CubeMX is a graphical tool that simplifies the configuration of STM32 products, and generates the corresponding initialization code for the STM32 Project.

## Installation Steps
1. Go the the [STM32CubeMX Website](https://www.st.com/en/development-tools/stm32cubemx.html#get-software) and download the software
2. Install it to your laptop

As of now, STM32CubeMX is not needed but it is useful for the later parts of the software training.
